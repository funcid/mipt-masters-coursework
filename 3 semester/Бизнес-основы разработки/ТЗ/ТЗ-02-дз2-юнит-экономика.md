## 1. Цель

Рассчитать LTV, CAC, LTV/CAC, payback и break-even; сделать вывод об устойчивости юнита.

## 2. Объём и структура PDF

### Блок A. Титул + юнит (слайд/стр. 1)

- Проект FuncFund
- Юнит = **1 платящий клиент** (SaaS/подписка) + обоснование

### Блок B. Таблица расчётов (обязательна)

| Показатель | Формула LMS | Значение FuncFund | Допущение |
|---|---|---|---|
| AOV | средний чек | … | … |
| Margin | (AOV − переменные)/AOV | … | эквайринг, инфра |
| LT | время жизни | … | churn |
| LTV | AOV × Margin × LT | … | … |
| CAC | маркетинг / клиенты | … | каналы |
| LTV/CAC | LTV÷CAC | … | норма ≥3 |
| CAC Payback | CAC/(AOV×Margin) | … | … |
| Break-even | Fixed / ((AOV×Margin)−CAC) | … | opex пилота |

Единицы (мес./год) согласовать внутри таблицы и подписать.

### Блок C. Слайды выводов (4–5)

1. Проект + юнит  
2. LTV, CAC, LTV/CAC, Payback + стресс-тест (отток ×2/×3, CAC ×2)  
3. **График** точки безубыточности (обязателен: рубрика «качество отчёта с графиками»)  
4. Выводы: устойчив ли? слабое место? + график LTV/CAC по сценариям  
5. Рекомендации
