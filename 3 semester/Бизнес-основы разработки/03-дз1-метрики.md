> В силлабусе ДЗ модуля 3 названо «проведение product discovery», в теле задания — система метрик. Делать по **тексту задания** (метрики + гипотезы).

## Цели

- выбирать, обосновывать и интерпретировать ключевые метрики в реальном бизнес-кейсе;
- отличать vanity metrics от actionable metrics;
- строить гипотезы на основе данных.

## Часть 1. Контекст и выбор продукта

Кейс: продукт проектного практикума (**FuncFund**). Указать:

- [ ] название продукта;
- [ ] Value Proposition (основная ценность для пользователя);
- [ ] бизнес-модель (как зарабатывает: подписка / реклама / комиссия / freemium / …);
- [ ] целевую аудиторию.

## Часть 2. Цели и ключевые метрики (AARRR)

Заполнить таблицу Pirate Metrics (Acquisition → Activation → Retention → Referral → Revenue) по образцу LMS.

В текстовом пояснении к таблице ответить:

- [ ] как определён момент «активации» пользователя; описать Aha-момент;
- [ ] единственная North Star Metric — какая и почему;
- [ ] как метрики связаны с бизнес-моделью.

## Часть 3. Анализ данных и гипотезы

Выбрать **один** сценарий:

- **A:** Retention D7 упал на 15%;
- **B:** Activation вырос на 25%, Revenue без изменений.

Ответить:

1. [ ] 3–4 возможные причины изменения;
2. [ ] 2 проверяемые гипотезы (формат: «считаем, что … → если … → метрика вырастет на N%»);
3. [ ] конкретные шаги проверки (A/B, опрос, углублённая аналитика, …).
