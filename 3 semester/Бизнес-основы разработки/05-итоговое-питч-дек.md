## Цели

- закрепить структуру питч-дека;
- отработать презентацию и защиту проекта.

## Обязательная структура (10 слайдов)

### 1. Title

- [ ] название проекта;
- [ ] слоган в **одну строку** (суть ценности);
- [ ] ФИО участников и роли;
- [ ] контакты.

### 2. Problem

- [ ] 2–3 факта, что проблема реальна;
- [ ] для кого (ЦА);
- [ ] данные / цитаты / истории;
- [ ] формат: «Сегодня [ЦА] сталкивается с тем, что… Это приводит к…».

### 3. Solution

- [ ] решение **одним предложением**;
- [ ] без технических деталей, фокус на ценности;
- [ ] формат: «Мы предлагаем [продукт], который позволяет [действие], решая проблему [проблема]».

### 4. Product

- [ ] только **3** ключевые функции под главную боль;
- [ ] визуал: скриншоты / схема / прототип / демо;
- [ ] уникальное преимущество.

### 5. Market Size

- [ ] TAM / SAM / SOM;
- [ ] top-down схема;
- [ ] актуальная статистика + обоснование размера рынка.

### 6. Business Model

- [ ] схема: кто клиент → что покупает → сколько платит;
- [ ] модель монетизации;
- [ ] CAC и LTV (если можно оценить).

### 7. Competition

- [ ] конкуренты и чем вы лучше;
- [ ] матрица позиционирования (напр. Цена × Качество/Функционал);
- [ ] УТП.

### 8. Marketing & Traction

- [ ] каналы привлечения **или** план первых 1000 пользователей;
- [ ] первые результаты: рост, пользователи, отзывы, партнёрства (если есть).

### 9. Financials

- [ ] таблица выручки и расходов на ближайший год;
- [ ] график прогноза выручки на **3 года**;
- [ ] выручка, основные расходы, валовая прибыль;
- [ ] сумма искомых инвестиций.

### 10. Ask

- [ ] конкретная сумма и на какой срок;
- [ ] разбивка (пример LMS: 40% маркетинг / 30% разработка / 20% зарплаты / 10% opex);
- [ ] ключевые вехи на эти деньги (запуск, пользователи, окупаемость).

## Формат и сроки

- один файл **PDF** в форму сдачи;
- дедлайн сдачи PDF — **11.01.2027**;
- защита устно — **18.01.2027**;
- проверка с комментариями преподавателя.
