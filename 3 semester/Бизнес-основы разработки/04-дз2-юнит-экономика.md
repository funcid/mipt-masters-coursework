## Цели

Рассчитать ключевые метрики юнит-экономики, оценить прибыльность одного клиента и понять условия устойчивости бизнеса.

## Часть 1. Определение юнита

- [ ] Чётко сформулировать, что является «юнитом», с обоснованием.
- Ориентиры LMS:
  - E-commerce / SaaS / Marketplace → 1 платящий клиент;
  - мобильное приложение → 1 активный пользователь (DAU/MAU);
  - производство / услуга → 1 проданная единица.

Для FuncFund (SaaS/подписка): логичный юнит — **1 платящий клиент**.

## Часть 2. LTV (Lifetime Value)

Рассчитать и зафиксировать допущения, если данных мало:

1. [ ] **AOV** — средний чек за транзакцию  
   `AOV = сумма покупок / число покупок`
2. [ ] **Margin** — маржа без постоянных затрат  
   `Margin = (AOV − переменные затраты на юнит) / AOV`
3. [ ] **LT** — среднее время жизни клиента (мес./годы)
4. [ ] **LTV**  
   `LTV = AOV × Margin × LT`

## Часть 3. CAC

- [ ] `CAC = затраты на маркетинг и рекламу за период / число привлечённых клиентов`
- [ ] Описать каналы привлечения и почему они выбраны
- [ ] Включить в CAC зарплату маркетолога / долю своего времени на привлечение

## Часть 4. Анализ метрик

- [ ] `LTV / CAC` (здоровый бизнес: **LTV ≥ 3 × CAC**, минимум LTV > CAC)
- [ ] **CAC Payback** = `CAC / (AOV × Margin)`
- [ ] Интерпретация: выполняется ли правило? что значит срок окупаемости для бизнеса?

## Часть 5. Точка безубыточности

- [ ] Постоянные расходы в месяц (аренда, зарплаты, подписки, …)
- [ ] Прибыль с клиента после CAC ≈ `(AOV × Margin) − CAC`
- [ ] `Break-even (юниты/мес) = Постоянные расходы / ((AOV × Margin) − CAC)`
- [ ] Оценка реалистичности цифры

## Формат сдачи

1. Таблица с расчётами по всем этапам.
2. Краткий отчёт-презентация **4–5 слайдов**:
   - слайд 1 — проект и определение юнита;
   - слайд 2 — LTV, CAC, LTV/CAC, CAC Payback;
   - слайд 3 — график точки безубыточности;
   - слайды 4–5 — выводы и рекомендации (устойчив ли проект? слабое место? что улучшить?).
