# Домашнее задание 1. Документоориентированные базы данных на примере MongoDB

Дисциплина: Нереляционные базы данных  
Форма проверки: домашнее задание для самостоятельной практики (не входит в итоговое оценивание)

Выполнено в консоли `mongosh` на локальной MongoDB (`docker compose up -d` в этой папке).

## Подготовка базы данных

```javascript
use school_db

db.students.insertMany([
    { name: "Анна", age: 20, course: 1, subjects: ["математика", "физика"], GPA: 4.5 },
    { name: "Иван", age: 22, course: 3, subjects: ["информатика", "математика"], GPA: 4.2 },
    { name: "Мария", age: 19, course: 1, subjects: ["литература", "история"], GPA: 4.8 },
    { name: "Петр", age: 21, course: 2, subjects: ["физика", "химия"], GPA: 3.9 },
    { name: "Елена", age: 20, course: 2, subjects: ["биология", "химия"], GPA: 4.1 }
])
```

Результат: база `school_db` создана, в коллекцию `students` вставлено 5 документов.

## Задание 2. Поиск по условию

Найти всех студентов первого курса.

```javascript
db.students.find({course: 1})
```

Результат — 2 документа (Анна и Мария), у обоих `course = 1`:

```json
[
  { "name": "Анна",  "age": 20, "course": 1, "subjects": ["математика", "физика"],  "GPA": 4.5 },
  { "name": "Мария", "age": 19, "course": 1, "subjects": ["литература", "история"], "GPA": 4.8 }
]
```

Чек-лист:

- использован фильтр `{course: 1}`
- получено 2 документа (Анна и Мария)
- у всех студентов `course = 1`

## Задание 3. Сложный фильтр

Найти студентов со средним баллом выше 4.0 и возрастом младше 21 года.

```javascript
db.students.find({GPA: {$gt: 4.0}, age: {$lt: 21}})
```

Фактический результат — 3 документа (Анна, Мария и Елена). В методичке указаны только Анна и Елена, но Мария тоже подходит: `age = 19 < 21` и `GPA = 4.8 > 4.0`.

```json
[
  { "name": "Анна",  "age": 20, "course": 1, "subjects": ["математика", "физика"],  "GPA": 4.5 },
  { "name": "Мария", "age": 19, "course": 1, "subjects": ["литература", "история"], "GPA": 4.8 },
  { "name": "Елена", "age": 20, "course": 2, "subjects": ["биология", "химия"],    "GPA": 4.1 }
]
```

Чек-лист:

- использован оператор `$gt` для `GPA`
- использован оператор `$lt` для `age`
- получено 3 документа, все соответствуют условиям (`GPA > 4.0` и `age < 21`)

## Задание 4. Обновление документа

Повысить средний балл Марии на 0.2.

```javascript
db.students.updateOne(
  {name: "Мария"},
  {$inc: {GPA: 0.2}}
)

db.students.find({name: "Мария"})
```

Результат обновления: `matchedCount: 1`, `modifiedCount: 1`.

Документ Марии после обновления:

```json
{ "name": "Мария", "age": 19, "course": 1, "subjects": ["литература", "история"], "GPA": 5.0 }
```

Чек-лист:

- использован `updateOne()` для одного документа
- использован оператор `$inc` для увеличения `GPA`
- `GPA` Марии стал `5.0`
- остальные поля не изменились

## Дополнительная практика

### Добавить нового студента

```javascript
db.students.insertOne({
    name: "Олег",
    age: 23,
    course: 4,
    subjects: ["информатика", "математика"],
    GPA: 4.3
})
```

### Удалить студента с самым низким GPA

Самый низкий GPA — у Петра (3.9).

```javascript
const lowest = db.students.find().sort({GPA: 1}).limit(1).toArray()[0]
db.students.deleteOne({_id: lowest._id})
```

### Найти всех студентов старше 20 лет

```javascript
db.students.find({age: {$gt: 20}})
```

После удаления Петра остаются Иван (22) и Олег (23):

```json
[
  { "name": "Иван", "age": 22, "course": 3, "subjects": ["информатика", "математика"], "GPA": 4.2 },
  { "name": "Олег", "age": 23, "course": 4, "subjects": ["информатика", "математика"], "GPA": 4.3 }
]
```
