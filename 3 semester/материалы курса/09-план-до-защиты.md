## Что нельзя пропускать

| Требование | Зачем |
|---|---|
| Пройденный акселератор | Иначе не допустят к защите |
| MVP на реальных клиентах и следы пилота/оплат | Иначе не допустят; на защите смотрят коммерциализацию |
| Зачёт НИР 3 (презентация 50% + отчёт 50%) | Отчёт блокирующий: провал по одному критерию = незачёт |
| Зачёт НИР 4 и предзащита | Нужны для выхода на ГИА |
| Папка проекта целиком при сдаче | Обязательный формат |
| Личная гипотеза ДС, теория, методика, ≥130 часов | Критерии отчёта |
| БФТ, узкая аудитория, метрики эксперимента | Нужны для пилота и презентаций |
| Позиционирование без советов «покупай / продавай» | Ограничение курса и регуляторика |
| Внешний питч, акселератор или грант | Критерий ГЭК по развитию проекта |
| Письма поддержки, гранты или оплаты | Доказательства спроса на защите |
| Связь с критическими технологиями РФ | Критерий инновационности |
