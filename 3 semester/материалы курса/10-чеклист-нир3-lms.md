Синхронизировано с LMS `Справочник студента 2025/27` (раздел «НИР 3 по треку Стартап») на **20.10.2026**.  
Рабочий план с датами: [`09-план-до-защиты.md`](09-план-до-защиты.md). Черновики: [`../FuncFund_ВКРС/I — НИР 3/черновики/`](../FuncFund_ВКРС/I%20—%20НИР%203/черновики/).

## Цель семестра (групповые / соло)

- [ ] MVP для 1–2 сегментов, ключевые функции без критических багов
- [ ] Техдок в git + пользовательская документация (оферта/ПД согласованы с продуктом)
- [ ] Бета-тесты (≥5 протоколов), бэклог доработок, аргументация выборки
- [ ] Рабочая гипотеза продукта + УЦП + метрики успеха/провала
- [ ] Go-to-market (каналы, охват, план пилота 4 сем., CAC/LTV ориентиры)
- [ ] Финмодели: юнит-экономика, P&L ~3 года, точка безубыточности; обновлён Остервальдер
- [ ] (ДС/ML) baseline, ≥2 подхода, пайплайн оценки, метрики качества
- [ ] (для «отлично») LOI / намерение платного пилота от 2–3 клиентов

## Личные (профиль ДС)

- [ ] Личная исследовательская гипотеза: однозначная, опровержимая, с цифрами
- [ ] Теоретический анализ источников → из него следует гипотеза
- [ ] Методика по шагам (данные, объект, критерий успеха)
- [ ] Эксперименты + интерпретация результатов
- [ ] ≥130 ч исследовательских/производственных задач в дневнике (~9 ч/нед)
- [ ] Артефакты профиля (не «оргзадачами»)

## Аттестация

| Часть | Когда | Вес | Минимум |
|---|---|---:|---|
| Промежуточная презентация | окт–нояб | 50% | средний ≥3 и каждый критерий ≥3 |
| Отчёт НИР 3 | декабрь | 50% | каждый критерий ≥3; **блокирующий** |

Тайминг соло: **4 мин** общие + **5 мин** личные + **8 мин** Q&A.

- [ ] Черновик отчёта НР **≥ за 1 неделю** до формы сдачи

### Критерии отчёта (×0,2 каждый)

1. Профильность и полнота роли (≥130 ч)
2. Теоретический анализ
3. Исследовательская гипотеза
4. Методика
5. Полезность результатов → готовность MVP к первым продажам

## Ритм

- Еженедельно: статус НР (сделано / блокер / план)
- Раз в 2 недели: письменный спринт-отчёт
- Окт / нояб: запись на консультации + семинары-чекпойнты
- Не пропускать: акселератор (допуск к защите), беты, зачёт НИР 3
