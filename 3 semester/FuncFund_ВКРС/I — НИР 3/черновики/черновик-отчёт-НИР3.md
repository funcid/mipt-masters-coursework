## 1. Общая информация о проекте

**FuncFund** — сервис агрегации и аналитики личного инвестиционного портфеля для DIY-инвесторов MOEX с 2+ счетами. Продукт показывает структуру, динамику и риск-метрики и **не** выдаёт инвестиционные рекомендации.

**Цели 3 семестра (командные = соло):**

1. Довести MVP до состояния, пригодного для бета-теста и демонстрации комиссии.
2. Проверить рабочую гипотезу продукта и личную гипотезу ДС на реальных пользователях.
3. Подготовить GTM и финмодель пилота на платящих (исполнение — 4 сем.).
4. Пройти промежуточную презентацию и сдать отчёт НИР 3.

**Результаты на 20.10 (промежуточные):** mobile MVP (auth, dashboard+WS, импорт Сбер, manual assets, history, Premium/ЮKassa), legal, демо НР; в работе — 2-й брокерский импорт, бета-протоколы, документы гипотез (этот пакет).

**Репозиторий:** https://github.com/funcid/funcfund  
**Delivery сент–окт:** 12 коммитов, ~317 файлов, ключевые фичи billing/import/history/dictionary (см. снимок KPI).

## 3. Личные рабочие гипотезы

### 3.1. Рабочая гипотеза продукта

См. полный текст: [`A8-гипотеза-продукта-УТП-метрики.md`](A8-гипотеза-продукта-УТП-метрики.md).

Кратко: при MVP с импортом ≥1 брокера + ручным добором + единым дашбордом **≥60%** бета (n≥5) оценят закрытие боли сверки ≥7/10 и **≥40%** заявят готовность платить ~2 990 ₽/год (при условии 2-го источника).

### 3.2. Личная гипотеза ДС

См. [`A9-личная-гипотеза-ДС.md`](A9-личная-гипотеза-ДС.md).

Кратко: пайплайн импорт→dictionary→valuation→ClickHouse даёт parse success ≥80% и относительную ошибку оценки ≤5% у ≥80% успешных кейсов; multi-source на одном экране для тестовой группы.

**Метрики:** parse success rate; valuation relative error; time-to-value; multi-source rate.

**Источники:** CustDev 14 интервью; конкурентный анализ; документация MOEX/брокеров; код пайплайна в репозитории.

## 5. Подходы и методика

**Методология:** lean startup + hypothesis-driven development; для ДС — measurement of data pipeline quality.

**Методика проверки H_DS (шаги):** см. A9 §«Методика» и A10.

**Стек:** Kotlin microservices, PostgreSQL, ClickHouse, Redis, OpenSearch, Expo mobile, ЮKassa, OTel/Grafana.

**Baseline:** rule-based Сбер HTML parser (без ML). Сравнение подходов: (A) только manual; (B) Сбер+manual; (C) +второй брокер — по готовности.
