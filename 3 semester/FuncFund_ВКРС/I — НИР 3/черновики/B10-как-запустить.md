# B10. Как запустить / посмотреть MVP (1 страница)

**Дата:** 03.11.2026 · Код: https://github.com/funcid/funcfund · Демо: **https://funcfund.ru**

## Вариант A — демо (рекомендуется комиссии)

1. Открыть https://funcfund.ru (PWA).  
2. Регистрация / OAuth Яндекс или VK.  
3. Импорт: Сбер HTML **или** подключение Т-Инвестиции; при необходимости — ручные активы.  
4. Дашборд: структура, live-котировки (WS), history (Premium).  
5. Checkout Premium — ЮKassa (прод-цены на бэке).

Deploy-kit без секретов: `deploy/vps-demo/` · runbook апдейта: `deploy/vps-demo/README.md`.

## Вариант B — локально (разработчик)

```bash
git clone https://github.com/funcid/funcfund.git
cd funcfund/microservices/infra
# поднять compose (Postgres, ClickHouse, OpenSearch, сервисы) — см. docker-compose.yaml
# mobile: cd ../../mobile && npm i && npx expo start
```

Детали env/OAuth/ЮKassa — в README корня и `mobile/README.md`. Секреты не коммитить.

## Что считать «работает»

- Регистрация и JWT  
- ≥1 источник данных на дашборде  
- Котировки/снапшот без P0-краша  
- (опц.) путь до оплаты  

Дисклеймер: продукт **не** даёт инвестрекомендаций.
