# B11. Go-to-market волны 1 (черновик)

**Проект:** FuncFund · **Дата:** 03.11.2026 · **ICP:** DIY-инвесторы MOEX с 2+ счетами, боль ручной сверки  
Источники: CustDev n=14 · задание 5.2 · README roadmap · A8

## 1. Оффер (одной фразой)

«Один дашборд вместо Excel: импорт Сбер/Т + ручные активы, live-структура портфеля — **без** сигналов buy/sell.»

**Цена волны 1:** Premium **349 ₽/мес** (якорь года **2 990 ₽**); demo/checkout через ЮKassa на https://funcfund.ru.

## 2. Три канала (приоритет)

| # | Канал | Что делаем | Охват / механика | Как меряем |
|---|---|---|---|---|
| 1 | **Telegram / чаты MOEX** | Посты + мини-гайд «сверка за 15 мин»; инвайт в бету | ICP сидит в чатах; low CAC | UTM / «откуда узнали» · CAC |
| 2 | **Контент (VC.ru / YouTube shorts / Habr)** | 3–5 материалов: боль multi-broker, импорт без API, дисклеймер «без рекомендаций» | Органика + доверие | CTR→регистрация→import success |
| 3 | **Рефералы беты / CustDev** | 14 согласий уже есть; протокол → «приведи 1 с 2+ счетами» | Тёплый трафик | % приглашённых → pay |

Волна 2 (не сейчас): SEO под «учет портфеля», партнёры-авторы, startup-окна банков.

## 3. Путь до оплаты (воронка)

```text
осознание боли (контент/чат)
  → регистрация / OAuth (Яндекс|VK|email)
  → импорт Сбер или connect Т (+ manual)
  → «aha»: единый дашборд <15 мин
  → Premium checkout (ЮKassa)
  → удержание: history/WS, напоминание сверки
```

**Критерии пилота 4 сем. (ориентиры):** первые 10 оплат · H3 import success ≥80% · churn не измеряем на НИР 3, закладываем в B12.

## 4. План пилота (связка с НИР 4)

| Неделя | Действие |
|---|---|
| 0 | ≥5 протоколов беты (D1), правки онбординга |
| 1–2 | 3 поста в каналах 1–2 + рефералка |
| 3–4 | Закрытие 10 Premium; фиксация CAC грубо |
| 5+ | Решение: масштаб / пивот парсеров / цена |
