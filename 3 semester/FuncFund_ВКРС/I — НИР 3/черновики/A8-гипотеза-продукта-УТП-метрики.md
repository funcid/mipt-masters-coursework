# A8. Гипотеза продукта, УТП и метрики успеха MVP

**Проект:** FuncFund · **Автор:** Царюк А. В. · **Версия:** 1.0 · **Дата:** 20.10.2026  
Согласовать с НР (задача B6). Источники: CustDev n=14, задание 5.2, README roadmap.

## Проблема (одно предложение)

DIY-инвесторы MOEX с 2+ счетами тратят от 15–20 минут до нескольких часов в месяц на ручную сверку Excel/приложений и не имеют единого окна структуры портфеля.

## ICP волны 1

Частные инвесторы РФ (MOEX), ≥2 источника (брокер + банк/второй брокер), ведут учёт вручную или в разрозненных приложениях, готовы платить за экономию времени **без** инвестрекомендаций.

## УЦП (уникальное ценностное предложение)

FuncFund даёт **одно окно агрегации и контроля** портфеля (импорт отчётов + ручной ввод + live-котировки + история), чтобы DIY-инвестор за минуты видел структуру и динамику по всем счетам — **без** сигналов buy/sell/hold и персональных рекомендаций.

Отличие от кабинетов брокеров: кросс-брокерность и внешние активы. Отличие от Snowball/Intelinvest: фокус на мультисчетах MOEX + импорт без привязки к одному брокеру + mobile-first.

## Рабочая гипотеза продукта (для пилотирования)

> Если DIY-инвестор MOEX с 2+ источниками получит MVP FuncFund с импортом ≥1 брокера, ручным добором позиций и единым дашбордом live+history, то **≥60% бета-участников (n≥5)** оценят продукт как «закрывает основную боль сверки» (≥7/10) **и** не менее **40%** заявят готовность платить ≥2 990 ₽/год (или эквивалент demo-оплаты) при условии появления 2-го источника импорта.

Связь с УЦП: проверяем, что ценность «единое окно без рекомендаций» ощущается на реальном сценарии сверки, а не только на CustDev-словах.

Подгипотезы (бизнес, из 5.2):

| ID | Формулировка | Метрика |
|---|---|---|
| H1 | Готовность платить при экономии времени | доля «готов платить» / demo-оплаты |
| H3 | Импорт покрывает онбординг без поддержки | success rate импорта ≥80% |
| H4 | Позиционирование «без рекомендаций» приемлемо | 0 системных претензий «ждали сигналы» |

| Метрика | Успех | Провал / пивот | Как меряем |
