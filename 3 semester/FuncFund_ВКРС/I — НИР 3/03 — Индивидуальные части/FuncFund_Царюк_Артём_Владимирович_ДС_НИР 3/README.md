1. **Продукт / CustDev** — сегменты, УТП, БФТ MVP, гипотезы пилота.
2. **Разработка / data** — MVP, пайплайны данных и оценки (профиль ДС), эксперименты, документация.
3. **Go-to-market и финансы** — каналы, модель, подготовка пилота на платящих пользователей (фокус 3→4 сем.).
