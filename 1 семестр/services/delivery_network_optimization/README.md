# Вариант 2: Оптимизация сети пунктов выдачи заказов

## Описание

Проект реализует алгоритм оптимизации сети пунктов выдачи заказов (ПВЗ). Система анализирует исторические данные о заказах, строит карту плотности спроса и предлагает оптимальные местоположения для новых ПВЗ.

## Запуск

```bash
python main.py
```

Или с указанием файлов:

```bash
python main.py input.json output.json
```

## Формат данных

Входные данные в формате JSON:
- `districts` - районы города (многоугольники)
- `historical_orders` - исторические заказы
- `existing_pickup_points` - существующие ПВЗ
- `task_parameters` - параметры задачи

Выходные данные:
- `demand_density_map` - карта плотности спроса
- `new_delivery_points` - координаты новых ПВЗ
- `delivery_zones` - зоны доставки
- `metrics` - метрики эффективности

## Алгоритмы

- **Интерполяция плотности**: Kernel Density Estimation (KDE)
- **Размещение ПВЗ**: Жадный алгоритм
- **Зоны доставки**: Диаграмма Вороного с ограничением по радиусу
